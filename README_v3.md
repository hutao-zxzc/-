## 🎯 为什么新系统更好？

### 旧系统的问题：

```python
# ❌ 规则判断 - 完全不可靠
if circularity > 0.7:
    if area_ratio > 0.4:
        return 'Q'  # 后
    else:
        return 'P'  # 兵
```

**问题：**
- ❌ 识别率极低（<50%）

- ❌ 需要不断调整阈值
- ❌ 无法适应不同棋子样式

### 新系统的方法：

```python
# ✅ 深度学习 - 自动学习特征
model = CNN()
model.train(images, labels)  # 从照片学习
result = model.predict(image)  # 直接预测
```

**优势：**
- ✅ 识别率高（95%+）
- ✅ 自动学习棋子特征
- ✅ 不需要规则判断
- ✅ 可以训练任何棋子样式

## 📸 如何准备训练照片？

### 方式1：从棋盘自动截取（推荐）

```bash
python capture_pieces.py
```

**步骤：**
1. 校准棋盘位置
2. 移动几步棋
3. 按Enter截图
4. 标注每个格子的棋子类型
5. 重复3次以增加多样性

**优点：**
- ✅ 自动提取格子
- ✅ 包含你的实际棋盘样式
- ✅ 快速收集数据

### 方式2：直接拍摄棋子

把棋子放在纯色背景上：
- 从不同角度拍摄
- 确保光线充足
- 每种棋子至少20张

### 方式3：从网上下载

- 下载清晰的国际象棋棋子图像
- 确保与你的棋子相似

## ⚠️ 常见问题

### Q: 训练需要多久？
A: 取决于照片数量和硬件
   - 260张：10分钟（CPU）/ 2分钟（GPU）
   - 650张：20分钟（CPU）/ 5分钟（GPU）

### Q: 准确度不够高？
A:
1. 增加照片数量（每种至少50张）
2. 确保照片质量高
3. 尝试不同的棋子位置
4. 增加训练轮数

### Q: 必须从棋盘截图吗？
A: 不必！可以直接拍摄棋子照片，或从网上下载。关键是照片要与你的棋子相似。

### Q: 可以用其他棋子样式吗？
A: 可以！只要准备对应照片，系统可以训练任何棋子样式。
